## File analysis with location and model references

Qingfeng 1.2.2 gives the AI more useful evidence for cleanup decisions, especially for files whose names are only hashes.

- Show the selected file's path, parent folder, directory purpose, and verified model references in the conversation. Expand **查看发送的分析资料** to inspect the actual analysis context.
- Resolve Ollama blob references through small local manifest files, including model tags, config versus weight layers, reference sources, and shared dependencies. Incomplete or missing indexes are reported; no match is never treated as proof that deletion is safe.
- Ask the model for a concrete retain / conditional cleanup / insufficient information decision, supported by directory and reference evidence, deletion consequences, recovery requirements, and the appropriate app's management entry point.
- Read model-index metadata in a cancellable background task. The selected file body is not read or uploaded; unrelated manifest fields are excluded. AI cannot execute cleanup.

Validated with 58 core checks, 8 loopback HTTP checks, and synthetic automatic-analysis, configuration, retry, and cancellation flows.
