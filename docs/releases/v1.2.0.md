## Storage accounting, expanded file discovery, and optional AI

- **Clearer capacity:** available space uses macOS's public important-usage estimate. The overview separates physical free space and system-reclaimable space. Apple's private category index and refresh timing can still differ.
- **More complete large-file discovery:** scan your whole home, hidden directories, Library, and Applications. Filter by type, sort by size or last access, and compare logical size with allocated disk space. Threshold and traversal limits are configurable; incomplete results are labeled.
- **Ask AI directly:** right-click a file or cache and choose Send to AI; analysis starts without another Enter. A draggable desktop icon opens or collapses the conversation.
- **Choose your model:** OpenAI-compatible, Anthropic, Gemini, and Ollama protocols with common provider presets, custom endpoints, and Keychain storage for API keys.
- **Your decision:** AI receives selected metadata and conversation context, not file contents or the full scan report. It cannot run commands or delete files. Scanning and cleanup remain local.

Validated with 52 core checks, 8 loopback HTTP checks, and synthetic app-flow checks. Real paid provider credentials were not used for validation.
