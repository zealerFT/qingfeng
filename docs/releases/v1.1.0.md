## Large-file batch cleanup

- Select individual files with checkboxes or use **全选当前结果** (Select All Current Results).
- Review the selected count, total size, and full file paths, then confirm **批量移入废纸篓** (Move Selection to Trash).
- Files are rechecked before moving. Changed files and failures are skipped and recorded individually in History.
- Changing pages clears the selection. Protected locations, app packages, hidden paths, and files outside your home directory remain view-only.

## Download and install

**[Download Qingfeng 1.1.0 for Apple Silicon](https://github.com/zealerFT/qingfeng/releases/download/v1.1.0/Qingfeng-1.1.0-AppleSilicon.zip)**

Quit Qingfeng, extract the ZIP, and drag **清风.app** into **Applications**, choosing **Replace** for an existing installation. No compilation is required. Requires macOS 14 or later and Apple Silicon, including M3. The app interface is Simplified Chinese.

The app is ad-hoc signed and is not notarized by Apple. If macOS blocks a download you trust, try opening it once, then use **System Settings → Privacy & Security → Open Anyway**, if offered.

Files move to the system Trash. Review or restore them there before emptying Trash yourself to reclaim space.
